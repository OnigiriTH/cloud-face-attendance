# ระบบเช็กชื่อผ่านใบหน้า (Smart Face Attendance System)
### รายวิชา: เทคโนโลยีกลุ่มเมฆ (Cloud Computing) โดย อ.เปรม

---

## 📌 คุณสมบัติของระบบ (Features)
1. **การตรวจจับและจำแนกใบหน้าแบบ Real-time:** เชื่อมต่อกับโมเดล Google Teachable Machine ที่เทรนไว้ (ตรวจจับ `PUN`, `NAM`, `B`)
2. **ระบบยืนยันตัวตน (Hold to Confirm):** เมื่อ AI มั่นใจ $\ge 90\%$ และมองกล้องค้างไว้ 1.5 วินาที ระบบจะทำการบันทึกเช็กชื่อทันที
3. **ระบบป้องกันการเช็กชื่อซ้ำ (Duplicate Prevention):** คนเดิมที่เช็กชื่อไปแล้วในวันนั้น จะไม่ถูกบันทึกซ้ำ
4. **ระบบเสียงตอบรับสองทาง (Audio Feedback):**
   - เสียงเอฟเฟกต์ "ติ๊ง" (Web Audio API Synthesizer)
   - เสียงพูดสังเคราะห์ภาษาไทย "เช็กชื่อสำเร็จ คุณ..." (Web Speech API)
5. **ตารางสรุปรายชื่อผู้เข้าเรียน (Attendance Table):** แสดงเวลา, เปอร์เซ็นต์ความมั่นใจ, สถานะ และมีปุ่มดาวน์โหลดเป็นไฟล์ CSV
6. **การเชื่อมต่อคลาวด์ (Cloud Integration with Google Sheets):** ส่งข้อมูล วันที่, เวลา, ชื่อ และความมั่นใจ เข้าสู่ Google Sheets อัตโนมัติผ่าน Google Apps Script Web App

---

## 🚀 ขั้นตอนการเปิดใช้งานระบบ

### ขั้นตอนที่ 1: ตั้งค่า Google Sheets (ทำครั้งเดียว)
1. เปิดเว็บไซต์ [Google Sheets](https://sheets.new) เพื่อสร้างตารางใหม่ (ตั้งชื่อไฟล์ตามต้องการ เช่น "บันทึกการเข้าเรียน")
2. ไปที่เมนูด้านบนเลือก **ส่วนขยาย (Extensions)** ➔ **Apps Script**
3. ลบโค้ดในหน้าต่างเดิมออกทั้งหมด แล้วเปิดไฟล์ `google_apps_script.js` ก๊อปปี้โค้ดทั้งหมดไปวาง
4. กดปุ่ม **บันทึก (Save)** (รูปแผ่นดิสก์)
5. กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** ➔ เลือก **การทำให้ใช้งานได้ใหม่ (New deployment)**
6. ในหน้าต่างตั้งค่า:
   - **เลือกประเภท:** เว็บแอป (Web app)
   - **คำอธิบาย:** ระบบเช็กชื่อ
   - **ปฏิบัติการในฐานะ:** ตัวฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง:** ทุกคน (Anyone)  *(สำคัญมาก ต้องเลือก Anyone เพื่อให้หน้าเว็บส่งข้อมูลเข้าได้)*
7. กด **ทำให้ใช้งานได้ (Deploy)** และอนุมัติสิทธิ์ (Authorize access)
8. คัดลอก **URL ของเว็บแอป (Web app URL)** (ที่ลงท้ายด้วย `/exec`)

---

### ขั้นตอนที่ 2: เปิดหน้าเว็บ `index.html` และเริ่มใช้งาน
1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (แนะนำให้เปิดผ่านส่วนขยาย **Live Server** ใน VS Code เพื่อให้กล้องและระบบเสียงทำงานได้สมบูรณ์)
2. วาง **URL ของเว็บแอป Google Apps Script** ลงในช่องด้านบน แล้วกด **"บันทึก URL"** (ระบบจะจำไว้ในเบราว์เซอร์ ไม่ต้องกรอกใหม่)
3. กดปุ่ม **"เริ่มเปิดกล้อง"** และกดยินยอม (Allow) ให้เบราว์เซอร์ใช้งานกล้อง
4. ยืนหน้ากล้องให้ AI ตรวจจับ:
   - เมื่อ AI ตรวจจับได้ความมั่นใจ $\ge 90\%$ แถบ Progress จะวิ่งจนครบ 1.5 วินาที
   - ระบบจะส่งเสียงแจ้งเตือน และบันทึกชื่อลงตารางในหน้าเว็บ พร้อมซิงค์ขึ้น Google Sheets ทันที!
